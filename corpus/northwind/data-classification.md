# Data Classification and Handling

## Classes
- **Public**: approved for publication, e.g. marketing material.
- **Internal**: default for business information, e.g. this handbook.
- **Confidential**: customer data, contracts, source code and unreleased product plans.
- **Strictly confidential**: personal data of special categories (e.g. health data), salary data and cryptographic keys.

## Handling rules
Confidential data may only be stored in Northwind-managed systems such as SharePoint, the code repositories and the ERP. Strictly confidential data must be encrypted at rest and access must be logged. Copying confidential data to personal devices or private cloud storage is prohibited.

## Generative AI tools
Only the internal assistant and the approved enterprise AI services may be used with Internal or Confidential data. Public AI chat services must not receive any data above the Public class. Strictly confidential data must never be entered into any AI tool.

## Sharing with externals
Confidential data may be shared with customers or suppliers only under a signed NDA, using SharePoint external sharing links that expire after 30 days.
